# Interactive Python Number Guessing Game

A polished, terminal-based number guessing game built in Python to test logic, track efficiency, and provide dynamic feedback.

## Features
* **Dynamic Target Generation:** Generates a randomized secret number for every new session.
* **Attempt Tracking & Scoring:** Keeps count of your guesses and evaluates your final efficiency score.
* **Conditional Feedback:** Provides intuitive hints to guide you closer to the target number.
* **Robust Input Handling:** Clean terminal exception handling to keep the gameplay smooth.

## Tech Stack
* **Language:** Python 3.x (Pure Python standard library)

## How to Run
1. Ensure you have Python installed on your system.
2. Clone or download the repository.
3. Run the script directly from your terminal:
   ```bash
   python interactive_number_game.py
